Cardmarket / Marktpreise

Standard (ohne Key): TCGdex liefert Cardmarket-Price-Guide (Low, Trend, Ø 1/7/30) und TCGPlayer – kostenlos.

Mit API-Key: Live-Angebote und günstigste Preise pro Zustand (NM, EX, GD …), sofern der Anbieter das liefert.

So bekommst du einen Key
1. Bei einem Anbieter registrieren, z. B. cardmarketapi.com, API.SH oder TCGAPIs
2. API-Key kopieren und hier einfügen
3. Basis-URL prüfen (siehe Anbieter-Docs) → Speichern
4. Karte in der Suche öffnen → Live-Block erscheint in den Details
Standard: TCGdex (funktioniert ohne Key). Externe Keys scheitern im Browser oft an CORS – dann bleiben die TCGdex-Preise.

Was die Daten bedeuten

  • Low / From – günstigstes Angebot
  • Trend – Cardmarket-Markttendenz
  • Ø 7 / 30 – gleitende Durchschnitte
  • Ohne Key: Zustand ≈ Ableitung aus Low/Trend
  • Mit Key: Zustand ≈ günstigstes Live-Listing dieser Condition (wenn die API Listings liefert)
